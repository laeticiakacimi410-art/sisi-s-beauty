## 📋 À propos du projet

**Sisi's Beauty** est une plateforme web de gestion et de réservation pour un salon de beauté.

Elle permet aux clientes de :
- consulter les prestations
- réserver des rendez-vous
- acheter des produits en ligne
- contacter le salon

Une interface administrateur permet de gérer les utilisateurs, produits, prestations et réservations.
